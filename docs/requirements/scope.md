# Project Scope

## User roles
1. Citizen / Reporter
2. Donor
3. Volunteer
4. NGO / Relief Organization
5. Administrator

## Core workflows
- Report a need and track its status.
- Offer donations and coordinate suitable matches.
- Manage NGO requirements and inventory.
- Assign volunteers and track tasks.
- Confirm receipt and maintain transparent records.

## Planned advanced capabilities
- AI-assisted report and item categorization.
- Location-based matching and maps.
- Notifications, analytics, and administrative review.

These requirements are a starting draft and must be reviewed before implementation.
